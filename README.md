# device-daq

上位机数据采集与帧解析的练习工具（C++17 / Windows / TCP）。

出发点很简单：设备不停往串口或网口上吐字节，软件怎么知道哪一段是一帧？这个仓库就是把这件
事从头做一遍——从收到一坨字节开始，到还原出一帧一帧的采样数据为止。

## 帧格式

```
帧头   2 字节   0xAA 0x55
长度   2 字节   payload 字节数（小端）
数据   N 字节   4 路 int16 模拟量
校验   2 字节   CRC16-Modbus，算的是「长度 + 数据」
```

## 目录

| 文件 | 说明 |
| --- | --- |
| `sim_server.py` | 模拟设备：每 100ms 发一帧，每 27 帧故意发一个坏帧（CRC 错或截断） |
| `client_step1.cpp` | 第一步：连上、收字节、按十六进制打印 |

## 编译

```bat
g++ -std=c++17 -O2 client_step1.cpp -o client_step1.exe -lws2_32
```

需要 MinGW-w64。用 MSVC 的话把 `#pragma comment(lib, "ws2_32.lib")` 去掉，在链接器里加
`ws2_32.lib`。

## 运行

两个窗口，先跑服务器再跑客户端：

```bat
python sim_server.py
client_step1.exe
```

默认连 `127.0.0.1:9527`，也可以自己指定：`client_step1.exe 127.0.0.1 9527`。
